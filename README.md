# Classical Cryptography Algorithms 🔐

This repository contains Python implementations of several classical cryptography (encryption and decryption) algorithms.  
It is designed for educational purposes and to demonstrate how traditional ciphers work.

## 📌 Implemented Algorithms
- Caesar Cipher
- Monoalphabetic Cipher
- Polyalphabetic Cipher
- Vigenere Cipher
- Playfair Cipher
- Rail Fence Cipher
- Row Transposition Cipher

## 🛠️ Technologies Used
- Python
